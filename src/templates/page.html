Formula Finder

What this app does

Formula Finder is a searchable collection of about 600 formulas for Mechanical Engineering students: Calculus, Statics, and general Math & Physics.

  • Search by name, e.g. “integration by parts” or “buoyancy”.
  • Browse with the Math and Physics tabs and the chapter buttons.
  • Offline: once installed, it works without internet.
  • Updates: when new formulas are added, a bar appears. Tap Reload.

These are personal study notes. Always check with your course material.

How to install it

✓ You're using the installed app.

📱 iPhone / iPad: open this page in Safari → tap Share (square with arrow) → Add to Home Screen → Add.

🤖 Android: open this page in Chrome → tap ⋮ → Install app (or Add to Home screen).

💻 Laptop: in Chrome or Edge, click the install icon on the right of the address bar. On a Mac in Safari: File → Add to Dock.
